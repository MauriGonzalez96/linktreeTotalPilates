# Linktree Total Pilates

Página estática tipo Linktree para **Total Pilates Fitness** (Neuquén Capital).

Diseño mobile-first con Tailwind CDN y paleta del turnero (`#E8611A` / `#C7510F`).

- Disciplinas: Spring Board, Reformer, Combo Chair, Balones, Funcional, Mat, Bosu, Bandas

## Cómo verla

```bash
npx --yes serve -l 5180 .
```

Abrí http://localhost:5180  
También podés abrir `index.html` (hace falta internet para Tailwind/fonts).
